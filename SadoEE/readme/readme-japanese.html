SadoEE v1.0.2

Party Stash と SadoQoL を一つにした MOD：新デザインのインベントリ画面にパーティ共有の無限収納箱、商人・学者・リッチのいる休息キャンプ、最大 32 人のパーティ、そして多数の快適性の向上。すべての機能は選択式のコンポーネントです。

ゲームバージョン 2.6.6 と 2.7.3。すべてのコンポーネントに EEex が必要です。

インストール

  1. EEex をインストールします。
  2. アーカイブをゲームフォルダ（chitin.key のある場所）に展開します。
  3. setup-SadoEE.exe を実行し、言語と必要なコンポーネントを選びます。
  4. InfinityLoader.exe (EEex) でゲームを起動します。

Party Stash や SadoQoL から移行する場合

SadoEE は両方の MOD を置き換えます（同じファイル）：まず Party Stash と SadoQoL の全コンポーネントをアンインストールし、それから SadoEE をインストールしてください。セーブはそのまま使えます：収納箱の中身、キャンプとその住人の名前は変わりません。

ゲーム内

インベントリ画面の金色の ? ボタンが収納箱画面の各部を説明します。キャンプへはワールドマップから：「移動」ボタンの上の羊皮紙です。

アンインストール

まずゲーム内で収納箱を空にしてください：重量の横の大きな袋を Ctrl＋左クリック。そうしないと、中身はセーブに残りますが、収納箱を再インストールするまで取り出せません。大人数パーティの場合、#40 をアンインストールする前にパーティを 6 人以下に戻してください。
