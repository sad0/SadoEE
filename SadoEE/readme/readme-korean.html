SadoEE v1.0.0

Party Stash와 SadoQoL을 하나로 합친 모드: 새로 디자인한 인벤토리 화면의 파티 공용 무한 보관함, 상인·학자·리치가 있는 휴식 야영지, 최대 32명의 파티, 그리고 다양한 편의성 개선. 모든 기능은 선택 가능한 구성 요소입니다.

게임 버전 2.6.6 및 2.7.3. 모든 구성 요소에 EEex가 필요합니다.

설치

  1. EEex를 설치합니다.
  2. 압축 파일을 게임 폴더(chitin.key가 있는 곳)에 풉니다.
  3. setup-SadoEE.exe를 실행하고 언어와 원하는 구성 요소를 고릅니다.
  4. InfinityLoader.exe (EEex)로 게임을 시작합니다.

Party Stash 또는 SadoQoL에서 옮겨 오는 경우

SadoEE는 두 모드를 대체합니다(같은 파일): 먼저 Party Stash와 SadoQoL의 모든 구성 요소를 제거한 뒤 SadoEE를 설치하세요. 저장 파일은 그대로 작동합니다: 보관함 내용, 야영지와 주민의 이름은 그대로 유지됩니다.

게임 안에서

인벤토리 화면의 금색 ? 버튼이 보관함 화면의 각 부분을 설명합니다. 야영지는 세계 지도에서 갑니다: 이동 버튼 위의 양피지.

제거

먼저 게임에서 보관함을 비우세요: 무게 옆의 큰 가방을 Ctrl + 왼쪽 클릭. 그렇지 않으면 내용물은 저장 파일에 남지만 보관함을 다시 설치할 때까지 꺼낼 수 없습니다. 대규모 파티라면 #40을 제거하기 전에 파티를 6명 이하로 줄이세요.
