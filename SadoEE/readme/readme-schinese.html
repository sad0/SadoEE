SadoEE v1.0.0

Party Stash 与 SadoQoL 合为一个模组：重新设计的物品栏页面上有一个全队共享的无限储物箱，休息营地里有商人、学者和巫妖，队伍最多 32 人，还有大量便利性改进。每项功能都是可选组件。

安装

  1. 安装 EEex。
  2. 将压缩包解压到游戏文件夹（chitin.key 所在位置）。
  3. 运行 setup-SadoEE.exe，选择语言和需要的组件。
  4. 通过 InfinityLoader.exe (EEex) 启动游戏。

从 Party Stash 或 SadoQoL 升级

SadoEE 取代这两个模组（使用相同文件）：请先卸载 Party Stash 和 SadoQoL 的所有组件，再安装 SadoEE。你的存档仍可正常使用：储物箱内容、营地及其居民都保留原有名称。

游戏内

物品栏页面上的金色 ? 按钮会讲解储物箱页面的每个部分。营地从世界地图进入：“旅行”按钮上方的羊皮纸。

卸载

请先在游戏中清空储物箱：按住 Ctrl 并左键单击重量旁的大包袋。否则其内容会留在存档中，但在重新安装储物箱前无法取用。使用大型队伍时，卸载 #40 前请将队伍减至 6 人或更少。
